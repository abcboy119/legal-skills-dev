# Triage-labels

De skills spreken in termen van vijf canonieke triage-rollen. Dit bestand mapt die rollen op de werkelijke labelstrings in de issue tracker van deze repo.

| Label in mattpocock/skills | Label in onze tracker | Betekenis                                     |
| -------------------------- | --------------------- | --------------------------------------------- |
| `needs-triage`             | `needs-triage`        | Maintainer moet dit issue nog beoordelen      |
| `needs-info`               | `needs-info`          | Wacht op meer informatie van de melder        |
| `ready-for-agent`          | `ready-for-agent`     | Volledig gespecificeerd, klaar voor AFK-agent |
| `ready-for-human`          | `ready-for-human`     | Vereist implementatie door een mens           |
| `wontfix`                  | `wontfix`             | Wordt niet opgepakt                           |

Als een skill een rol noemt (bijv. "pas het AFK-ready triage-label toe"), gebruik dan de bijbehorende labelstring uit deze tabel.

Pas de rechterkolom aan zodra je een ander vocabulaire gaat gebruiken.
